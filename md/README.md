## 内容约定
- 讨论稿保存某个主题的当前理解、案例映射和未决问题。这里的 RFC 只是专题讨论形式，不代表已批准的技术规范。
- 概念卡片保存可跨主题复用的概念。
- 案例记录真实任务中的观察，不把单个案例提升为普遍规律。
- 实验目录只记录真实执行过的验证；未执行的想法留在讨论稿中。
- 原始讨论只有在获得真实导出时才归档，不用摘要冒充逐字记录。

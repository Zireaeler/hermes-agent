# 策略选择与理性元推理

**工作性理解：** 策略选择本身也是一个决策问题。面对继续当前方法、局部调整、切换路线或重新研究等选项，需要考虑各自可能带来的信息和结果，以及所需成本。

## 与 Orchestra 的联系
Orchestra 在战略回顾时比较：继续当前路线是否仍有合理的成功路径；局部修正是否针对已定位的问题；新实验是否可能改变方案选择；替代路线是否值得调查；重新定义问题是否能打开新的解决空间。

不要求 Agent 精确计算数学期望值。重点是明确比较继续投入、获取新信息和切换策略的理由。

## 相关概念
- 沉没成本：已投入成本不能单独成为继续路线的理由。
- 信息价值：新信息是否可能改变当前决策。
- 可逆性：决定是否容易撤销。
- 切换成本：新路线需要放弃或重做哪些工作。

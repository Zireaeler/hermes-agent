# 实验与验证

本目录只记录真实执行过的实验和验证。尚未执行的想法留在相关讨论稿的“待验证”部分。

## 当前待验证问题
- 有无战略监督，对错误路线持续时间和最终任务质量有何影响？
- 独立重审能否识别原 Worker 忽略的关键假设？
- 新 Worker 读取原始目标和实际产物，是否比直接继承原 Worker 的总结更容易发现方向问题？
- 能力依赖检查能否发现验收方式与目标属性之间的缺口？
- 哪些死胡同信号有用，哪些会造成过度打断？

## 实验记录建议
每次实验单独建页，记录任务目标与初始条件、对照方式、模型与工具、提示词、执行过程、原始产物和日志位置、预先定义的评价标准、实际结果及不能外推的结论。

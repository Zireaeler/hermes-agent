# orchestra 实验归档

本目录保存三次负向 review 实验和使用过的 prompt。受控实验没有证明负向 review 相对普通独立 review 有稳定净收益，因此这些材料不是当前首版设计或永久 review 流程。

- [`scheduler-negative-review.md`](scheduler-negative-review.md)：第一对 scheduler 实验。
- [`rule-interpreter-review.md`](rule-interpreter-review.md)：第二对规则解释器实验。
- [`controlled-stockroom-review.md`](controlled-stockroom-review.md)：第三次受控库存实验。
- [`review-prompts.md`](review-prompts.md)：实验使用的普通、负向和 executor prompt。

当前设计见 [`../orchestra-design.md`](../orchestra-design.md)。
